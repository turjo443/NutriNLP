“Chicken breast with rice and broccoli”

1. Process the natural-language food description.

   * Low Calorie

# 4. Calorie-Class Label Creation

If the attached proposal specifies exact thresholds for Low, Medium, and High Calorie classes, use those thresholds exactly.

If the proposal does not define the thresholds, use this leakage-safe procedure:

1. Aggregate the dataset at dish level.
2. Create a fixed 80% development/training partition and a 20% final test partition using `random_state=42`.
3. Calculate the 33.33rd and 66.67th percentiles of `total_calories` using only the training partition.
4. Define:

   * Low Calorie: value at or below the first threshold
   * Medium Calorie: value above the first threshold and at or below the second threshold
   * High Calorie: value above the second threshold
5. Apply the same saved thresholds to both training and test data.
6. Store the thresholds in a configuration or metadata JSON file.
7. Display the exact thresholds in the README, report, and application.

Never calculate the class thresholds independently on the test set.
